create anonymous volume
docker run -d --rm -p 3000:80 --name feedback-app -v /app/temp 

anonymous volumes is located somewhere by docker. 
It is used if you need to persist some folders. node_modules etc .
After rm will be deleted.


Named volumes 
docker run -d --rm -p 3000:80 --name feedback-app -v feedback:/app/feedback -v
It is controled by docker, you can find the volume according to name. 


bind mount 
docker run -d --rm -p 3000:80 --name feedback-app -v feedback:/app/feedback -v "/home/vasa/Documents/udemydocker:/app:ro" 
Bind mount is not supervised by docker, is located on the local pc. Is used when you need to edit source data for example. 
You do not have to rebuild the image, after change in the source code. 

all 3 volume types together
docker run -d --rm -p 3000:80 --name feedback-app -v feedback:/app/feedback -v "/home/vasa/Documents/udemydocker:/app:ro" -v /app/temp -v /app/node_modules feedback-node:volumes
